# SarahVon

**Exploring questions through data, maps, and visualizations**

---

### Summary

I use data to investigate questions, identify patterns, and communicate findings clearly. My work spans data visualization, spatial analysis, and GIS, with an emphasis on data integrity and responsible interpretation. I value the process of moving from an initial question to a useful result, and I’m especially interested in projects that combine careful analysis, visual communication, and practical application.
